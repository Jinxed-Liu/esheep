# 牧场数据查询技能

先理解用户真正询问的量，再选择直接查询或通用计算计划。模型不得直接把相似字段当成同一个指标，也不得把相关原始记录冒充计算结果。

## 核心语义

- `current_herd`：当前在场、在群、存栏羊只。固定使用 App 共用的版本化当前状态规则：历史归档永远排除；旧版权威快照继续受信；其余档案由未撤销事件投影。不得把“没有离群事件”近似为当前在场。
- `born_lambs`：出生羔羊数。来源固定为 `ReproductionRecord(kind=lambing).lambCount` 的合计。
- `born_lamb_lifecycle`：按出生月份查询出生数及当前在群、死亡、出售、淘汰、转出。出生数来自产羔事件 `lambCount`；生命周期数量来自具有出生日期的羊只档案和离群记录。两种来源必须分列，不得假设能逐只对应或强行相减。
- `lambing_events`：产羔次数。来源固定为产羔事件条数。
- `sheep_profiles`：羊只档案数量或档案字段。`birthAt` 只表示档案中的出生日期，不代表本牧场产羔数。
- 其他直接查询使用 `weight_records`、`reproduction_records`、`health_records`、`feeding_records` 或 `inventory`。
- 跨记录派生体重值使用 `calculate_farm_data`。模型组合 `source → cohort/filter → partition → window → transform → analysis_scope → group → reduce → selection`，App 不按自然语言短语匹配专用指标。
- `cohort=current_in_herd` 表示截止时点仍在群的羊；`cohort=all_profiles` 表示全部非历史归档档案。`pen_membership=at_cutoff` 按截止时点圈舍归属；`at_measurement` 先保留羊只完整样本时间线，再验证相邻区间两端及区间内连续圈舍归属，不能删除中间样本后拼出虚假的“相邻”区间。历史圈舍表现与当前圈舍羊群表现不能混用。
- 未明确限定单一日期、单一批次、单一生命周期或单一总体值的群体变化率问题使用 `analysis_scope=complete`。必须采用同羊真实相邻称重区间，完整返回：总体、不同称重区间、生产批次、截至时点生命周期和数据完整性。单个首末跨期平均值只可补充，不能代替完整分析。
- 历史圈舍表现使用 `cohort=all_profiles + pen_membership=at_measurement`，并把当前在群、出售、死亡、淘汰和转出分开；只有用户明确询问当前仍在群的羊时才使用 `current_in_herd + at_cutoff`。区间起止不属于同一唯一生产批次时，必须落入跨批次、重叠或未分批次类别，不能强行归批。

## 工作流

1. 识别指标、时间范围、分组、筛选及关联条件。
2. 明细或直接聚合调用 `query_farm_data` 并填写 `query_kind`；跨记录差值、时间间隔和变化速率调用 `calculate_farm_data` 并填写完整算子计划。群体变化率默认使用完整分析，只有问题明确收窄时才使用 focused。
3. 直接查询根据 `query_kind` 固定真实数据源；通用计算器只执行类型化算子，不内置用户说法或派生指标名称。
4. App 在执行前校验全部筛选、分组、窗口和算子；任何不能完整执行的条件都必须拒绝，不能静默忽略。
5. App 本地执行 SwiftData 查询和计算，并返回事实契约版本、规范化参数、牧场时区、状态依据、未知数、投影一致性、数据来源、公式、样本数、均值/中位数/最小值/最大值、区间天数、羊只等权值、总增重/总观察天数口径及完整性。
6. 工具结果只是 harness 的观察材料。模型必须结合原问题继续生成直接答案；语义复核比较问题、调用参数、证据和候选答案，不一致时退回重做。
7. 成功查询和计算的证据随会话保存用于审计，但不会直接作为聊天答案展示。

## 边界

- 不允许用羊只档案出生日期替代产羔事件。
- 不允许把产羔次数替代出生羔羊数。
- 不允许把缺少日期的历史状态默认为在场；无法证明时返回未知或拒绝需要完整状态的统计。
- 不允许在物化档案与统一事实规则不一致时继续返回可能与首页、羊群页面不同的结果。
- 日期和月份必须使用牧场保存的 IANA 时区，不得依赖设备当前时区。
- 不知道分母、时间字段或生命周期口径时，说明缺少条件；不得用近似统计补齐。
- 不为新的自然语言说法增加字符串路由；业务语义由模型规划，算术和权限由 App 确定性执行。
- 当前设备本地数据不等于云端已经同步完成，结果必须保留数据来源说明。
