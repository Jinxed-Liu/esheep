# Poster fonts

The poster editor bundles the original, unmodified font files for offline use.

- Knewave Regular: https://github.com/google/fonts/tree/main/ofl/knewave
  - File: `Knewave-Regular.ttf`
  - License: `knewave-OFL.txt`
- Ma Shan Zheng Regular: https://github.com/google/fonts/tree/main/ofl/mashanzheng
  - File: `MaShanZheng-Regular.ttf`
  - License: `mashanzheng-OFL.txt`

Both accompanying SIL Open Font License notices are included in the app resources.
Retrieved on 2026-10-20. These fonts apply only to poster typography.
