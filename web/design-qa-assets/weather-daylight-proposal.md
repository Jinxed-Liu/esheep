# eSheep+ Web · 牧场天气与昼夜设计方案

版本：2026-09-29 · 已按方案完成本地 Web 实现；天气服务联调与生产发布待完成

## 1. 设计结论

保留当前已选定的牧场风景、横向导航、生产档案图片和蓝色主要操作。将固定风景升级为随所选牧场当地太阳阶段与真实天气变化的环境背景。

用户进入首页时能感受到牧场的天色和天气；查看数据、搜索或录入时，文字和操作保持清楚、稳定。

本方案包含视觉、交互、状态、数据、性能、素材和验收规则。配套交互预览只使用示例数据，用于比较光照、天气与面板的关系；没有连接生产天气、真实牧场或业务写入。预览中的时段选择器、天气选择器只用于设计评审，不进入正式产品。

## 2. 实施前已核实的现状

- 当前首页采用 `pasture-dashboard.jpg`，生产档案有羊只与圈舍两张独立图片。依据是 `web/AGENTS.md` 与 2026-09-27 更新后的 `DESIGN_SPEC.md`。
- `HomeDashboard.jsx` 已有天气摘要入口，但数据来自尚未接入的 `workspace.weather`；云端工作区返回 `weather: null`。
- 牧场领域模型和 Web Cloud V2 投影已有经纬度、位置名称和 IANA 时区字段。当前 Web 工作区组装只显式补入牧场名称与时区，需要补齐所选牧场的位置读取。
- iOS 的 `FarmLocationWeather.swift` 使用 WeatherKit，并已有天气类型、强度、云量、风力、昼夜和时间字段。两端可以统一视觉语义，渲染方式分别实现。
- 现有动效规范要求背景静止。本提案提出一个明确的新增例外：天气可以在首页顶部的有限区域持续运动，同时提供静态模式和减少动态效果支持。正式实现前应将批准后的规则写回设计规范。

## 3. 信息架构与页面布局

### 3.1 首页

维持现有顺序：

1. 品牌与五个导航：首页 / 洞察 / 录入 / 投喂 / 搜索；右侧为牧场与账号。
2. 今日牧场：日期、牧场当地时间、天气摘要。
3. 在场羊只 / 有羊圈舍 / 今日投喂，保持现有口径。
4. 生产档案与今日操作。
5. 最近动态及已有运营内容。

天气摘要优先替换顶部问候语占用的位置，避免增加首页高度。桌面示例排版：

> 9 月 29 日 星期二 · 牧场当地 17:40
> 多云 · 22° · 日落 18:35　查看天气

数字仅为排版示例。天气更新时间与当地时钟分别显示，不能混用。

### 3.2 天气详情

- 桌面：点击摘要打开约 400–440px 的侧面板。面板为受控对话框，支持 Escape、关闭按钮、焦点约束及关闭后返回触发按钮。
- 移动端：内容自底部进入；长内容在详情内正常滚动，并始终保留可触达的关闭入口。
- 内容顺序：牧场所在地与当地时间 → 当前天气和体感温度 → 有效气象预警（如有）→ 未来 24 小时 → 未来 7 天（以可用数据为准）→ 日出日落和风、湿度等详情 → 来源与观测/更新时间。
- 预警显示发布机构、有效时间和来源链接。无预警数据时不宣称“无预警”。
- 天气详情不自动生成投药、饲喂量或生产操作建议。

### 3.3 其他页面

| 页面 | 背景范围 | 持续动画 |
| --- | --- | --- |
| 首页 | 顶部风景最完整，页面底部自然收敛为低对比底色 | 顶部天空与留白可见 |
| 洞察 | 延续当地天色，图表区域增加实底 | 仅顶部少量云层，可静态 |
| 录入 | 低对比环境底色，表单独立清晰 | 编辑期间暂停 |
| 投喂 | 低对比环境底色，计划、数字与状态清晰 | 编辑期间暂停 |
| 搜索及列表 | 顶部少量环境色，结果区域稳定 | 默认静态 |
| 对话框、菜单 | 使用稳定且足够不透明的面板 | 模态操作期间暂停背景 |

移动端保留五个目的地的底部导航；天气摘要最多两行，不挤压操作入口。

## 4. 时间规则：严格跟随牧场

### 4.1 唯一基准

输入为当前牧场的经纬度、IANA 时区、当地日期和当前 UTC 时刻。日出日落是该坐标在该日期的太阳事件，时区负责当地时间与日期的解释和显示。

- 不使用电脑时区决定牧场天色，也不使用固定的“06:00 天亮 / 18:00 天黑”。
- 同一时区的不同经度牧场也要得到各自的日出日落。
- 日期切换依据牧场当地午夜；日出、日落、黎明、暮色缓存随当地日期和位置版本失效。
- 正午是当地太阳过中天附近；不把民用时钟 12:00 当作所有牧场的太阳正午。
- 夏令时通过 IANA 时区处理，不能手写固定 UTC 偏移。
- 背景风景是品牌示意场景，没有经过测绘的朝向；太阳光位表现时段，不宣称与真实圈舍方位一致。

### 4.2 数据优先级

1. 使用天气服务提供的同一牧场、同一当地日期的太阳事件。
2. 服务不可用时，若有有效坐标，使用经过验证的太阳位置计算获得当天太阳事件，并标明日出日落为计算值。
3. 无有效坐标或无法得到可靠太阳事件时，使用中性静态背景；保留能够确认的当地时间，不推断固定时段日出日落。
4. 对极昼、极夜或当天无某个太阳事件的情况，显示明确状态，不伪造日出日落，不计算无效除法。

太阳位置与日出日落的关系可参考 [NOAA 太阳计算资料](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF)。正式实现应使用维护中的算法实现并用已知案例验证，不把 NOAA 在线计算器作为运行时依赖。

### 4.3 连续阶段

| 阶段 | 依据 | 视觉意图 |
| --- | --- | --- |
| 黎明 | 当地晨间曙光至日出 | 蓝灰天空，地平线逐渐暖起来 |
| 清晨 | 日出后的低太阳高度阶段 | 暖金色侧光，清透但不过亮 |
| 上午 | 清晨至太阳正午前 | 蓝色逐渐明亮，绿色自然 |
| 正午 | 太阳正午附近 | 中性日光，细节清晰，限制高光 |
| 午后 | 太阳正午后至低角度夕照前 | 从中性光逐渐变暖 |
| 傍晚 | 日落前的低太阳高度阶段 | 晴天出现柔和金色，厚云时减弱 |
| 暮色 | 日落至夜间 | 桃色、蓝紫逐渐进入深蓝 |
| 夜晚 | 暮色结束至次日黎明 | 深蓝地景，保留主体轮廓 |

实现时用连续的太阳高度/升降方向和太阳事件之间的进度驱动配色。阶段名称是关键画面标签，不是整点切换的图片列表。低太阳高度阈值、阶段插值曲线属于视觉参数，要用冬季、夏季与高纬度案例验证。

普通纬度下，曙光/暮光可用约定的太阳高度边界计算；高纬度白昼短、暮光长时，应保持连续进度，避免阶段重叠。不能将“深夜”机械绑定当地 00:00，也不能因用户所在城市入夜而改变牧场背景。

## 5. 天气规则

时间决定基础光照，天气决定云、能见度、降水和暖光衰减。两者组合，不能互相替代。

| 天气 | 光照和地景 | 动画 |
| --- | --- | --- |
| 晴 | 通透天空，自然草绿 | 少量高空薄云，光线稳定 |
| 多云 | 天空明暗适中，光线偏柔 | 远近两层云缓慢移动 |
| 阴 | 灰蓝天空，弱化直接阳光 | 厚云慢移，降低远景对比度 |
| 雨 | 冷灰色、远景朦胧 | 按实际降水强度调整雨线密度与速度 |
| 雨夹雪 | 冷灰天空 | 稀疏雨线与湿雪组合，控制总粒子数 |
| 雪 | 冷白或夜间灰蓝 | 大小、速度不同的雪花，随风轻移 |
| 雾 | 远山逐渐淡出，近景保留 | 低对比薄雾，运动极弱 |
| 雷雨 | 深灰云、低亮度环境 | 雨势明显，默认无闪电闪烁 |
| 未知 / 无有效数据 | 使用可靠太阳阶段对应的中性天空 | 无具象雨雪 |

风是附加参数，可与任何天气组合；风向只做装饰性运动方向，不表示场景的真实罗盘朝向。云量控制太阳光与星点的可见度。降水概率用于预报，不能直接触发正在下雨的背景。晨雾需天气支持；降雪不自动意味着地面积雪。没有观测依据时不增加积雪厚度、地面积水或模拟真实圈舍灯光状态。

月亮首版可采用不明确展示月相的柔和环境光；要展示具体月相、月升月落与位置时，必须有相应数据或经过验证的计算。月亮也可能白天出现，不将其机械当成夜间开关。

## 6. 图层与素材

从后向前：天空渐变 → 天体环境光 → 云层 → 远山/草地/羊群 → 地景色温与能见度 → 有限区域的雨雪 → 阅读保护层 → 页面内容。

- 动画层 `aria-hidden`、不参与焦点，使用 `pointer-events: none`。
- 具象动画主要位于顶部天空与页面留白，通过遮罩向下衰减；表格、数字和输入框不被粒子穿过。
- 内容的玻璃效果由较高不透明度底色、细边线和有限模糊构成。主操作蓝色、成功/警告/错误语义色不随天气变色。
- 整体背景不做视差漂移，不让山坡、羊群、文字同时晃动。

### 素材制作清单

1. 保持同一地平线、远山、羊群与圈舍构图的四组基础光照：清晨 / 日间 / 傍晚 / 夜间。
2. 可独立合成的天空与地景，避免晴天蓝天、固定阳光被保留到暴雨场景中。
3. 晴、多云、阴的云层素材与移动端裁切方案。
4. 雨雪粒子样式、远雾遮罩和地景保护遮罩。
5. 羊只档案与圈舍状态两张图片的配套环境色处理方案；不重新生成或改变品牌图标。
6. 为缺图、慢网与不支持效果的浏览器准备中性静态底图。

交互预览使用现有牧场图片加光照合成来展示方向。现有照片含固定的光照、云与阴影，所以预览不能视为最终夜景或雨景素材验收；正式资产须单独制作与评审。

## 7. 内容主题与环境天色

环境昼夜和阅读主题分别处理。

- 环境天色：依据牧场太阳阶段。
- 内容主题：跟随系统 / 浅色 / 深色，尊重用户选择。
- 夜间浅色主题：夜景搭配柔和浅色内容面板，降低纯白刺眼感。
- 白天深色主题：明亮风景搭配稳定的深色内容面板。
- 顶部直接叠在风景上的标题与天气文字，由阅读保护层保证对比度，不单靠文字阴影。
- 高对比度、减少透明度设置下提高面板不透明度，保持数据与焦点可见。

目标对比度按 WCAG AA 验证：普通文本 4.5:1，大文本 3:1，重要控件与焦点对比 3:1。应检查实际合成后最亮和最暗的背景，不能只检查颜色变量。依据：[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

## 8. 动效规范

| 触发 | 行为 |
| --- | --- |
| 首次打开 | 直接显示当前时段的静态底色，天气与细节就绪后淡入；不播放整天快进 |
| 自然时间流动 | 以低频更新目标光照，持续平滑过渡；不改变内容布局 |
| 天气更新 | 约 2–4 秒交叉过渡，旧粒子退出，新粒子进入 |
| 切换牧场 | 天气身份立即切换；有目标牧场有效缓存则使用，否则显示中性状态；不保留原牧场雨雪 |
| 后台回到前台 | 重新计算当前当地阶段，约 0.6–1.2 秒同步天色；天气按新鲜度重新获取 |
| 打开录入对话框 | 暂停环境持续动画，保留画面与表单内容 |
| 减少动态效果 | 停止云移动、雨雪移动与视差，以静态画面表达天气 |

以上时间是设计起点，需浏览器实测后定稿。连续动画默认最多 30fps；低性能设备采用静态降级。页面隐藏时停止绘制与非必要轮询，返回后只做一次过期检查，避免补跑积压帧。[Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)

外观设置提供“天气效果：自动 / 静态 / 关闭”。自动遵循系统减少动态效果并按性能降级；静态保留当前天气与昼夜画面；关闭使用普通应用底色，天气文字仍可查看。静态与关闭不改变天气数据本身。[减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

## 9. 数据与服务设计

建议复用 WeatherKit 的天气来源。Web 通过受认证的服务端接口访问 REST API；服务端持有签名密钥并处理配额、缓存和请求合并。Apple 的 REST API 支持 Web 平台，并要求来源标识。[WeatherKit REST API](https://developer.apple.com/documentation/weatherkitrestapi)

### 9.1 请求边界

- 请求以 `farmID` 指定牧场；服务端验证当前用户访问权，读取云端可信的牧场坐标。
- 位置变更继续走既有业务命令和审计管线；天气服务只读位置。
- 天气是独立的外部观测数据，不作为生产记录写入，不触发云端农场事实重放。
- 天气请求独立于工作区业务加载，不阻塞导航、首页数据或记录操作。
- 浏览器持有请求序号与位置版本；返回结果必须匹配当前牧场、位置版本和当天太阳数据。

### 9.2 建议数据契约

```text
FarmEnvironmentSnapshot
  farmID, locationRevision, timeZone, localDate
  fetchedAt, observedAt, expiresAt, source
  current: conditionCode, temperatureC, feelsLikeC,
           cloudCover, precipitationType, precipitationIntensity,
           windSpeedMps, windDirectionDeg, visibilityM
  solar: dawnAt, sunriseAt, solarNoonAt, sunsetAt, duskAt,
         source(provider/calculated), availability
  availability: current, hourly, daily, alerts
  attribution: mark, legalURL, providerLinks
```

字段为设计建议，不代表供应商原始字段。服务端适配为统一单位和语义，缺失项保持空值；需要明确原始云量、降水与风速单位。天气详情预报可以独立懒加载，不扩大首页响应。

### 9.3 缓存与新鲜度

- 首版当前天气建议 15 分钟缓存，优先服从供应商有效期。
- 缓存键至少包含牧场、位置版本、数据类型；太阳事件另含牧场当地日期。缓存命中也必须经过访问权限核对。
- 用户退出或牧场访问权撤销后清理相关浏览器状态，停止请求。
- `observedAt` 表示天气所对应的时刻；`fetchedAt` 表示请求完成时刻；天气 UI 不能把二者当成同一值。
- 请求失败后保留同牧场、同位置的最近天气，明确“更新暂缓”。建议最多容忍至观测时刻后 60 分钟，且不得超过供应商给定的硬失效时间；具体阈值可配置。
- 超过有效期停止具象雨雪，显示“天气暂不可用”。太阳计算与时钟仍可独立工作。
- 相同请求合并；失败指数退避，避免多标签页同时高频重试。

## 10. 异常状态与文案

| 状态 | 用户看到的内容 | 环境处理 |
| --- | --- | --- |
| 尚未设置位置 | 设置牧场位置；无管理权限显示“请联系牧场管理员设置位置” | 中性静态背景 |
| 位置无效 | 牧场位置需要更新 | 中性静态背景 |
| 天气初次加载 | 天气加载中 | 已知太阳阶段对应的中性底色 |
| 刷新短暂失败 | 更新暂缓 · 最近天气时间 | 在允许期限内保留最近状态 |
| 天气过期 | 天气暂不可用 | 移除具象雨雪，保留可靠昼夜 |
| 日出日落缺失 | 可计算时标注“根据牧场位置计算”；否则“日出日落暂不可用” | 不猜固定时间 |
| 当前时区缺失 | 牧场时区待确认 | 不把设备时间标成牧场时间 |
| 切换牧场 | 新牧场身份与加载状态 | 不闪现旧牧场天气 |
| 天气数据不支持预警 | 预警数据暂不可用或隐藏该分区 | 不显示“无预警” |

## 11. 性能与实现结构

建议拆为：`useFarmWeather`（独立请求）→ `resolveFarmEnvironment`（纯函数状态计算）→ `FarmEnvironmentBackground`（背景）与 `FarmWeatherSummary`（摘要）→ `FarmWeatherDetail`（详情）。名称为建议。

- CSS 表现天空配色、光照与少量云层；单个 Canvas 表现雨雪。首版无需增加 WebGL 依赖。
- 使用独立时钟与动画状态，逐帧更新不触发 React 业务组件重渲染。
- 雨雪粒子数设硬上限：桌面起始约 100–160，移动端约 30–60；按实测调整，粒子密度不是物理降水测量。
- Canvas 像素比上限建议 1.5，桌面可评估至 2；限制画布到实际动画区域。
- 不逐帧改变大面积模糊或生成图片。天气切换只预载目标状态的必要资源。
- 性能目标：新增天气绘制不产生大于 50ms 的长任务；代表设备上动画绘制耗时 p95 目标小于 4ms；未达标则自动减少粒子或静态降级。这些是验收目标，不是已获得的测试结果。
- 动态素材按需加载；首次静态背景沿用现有尺寸预算，新增首屏环境资源建议控制在 300KB 内，最终以质量和真实网络表现共同确定。

## 12. 分阶段交付

### A. 设计定稿

评审六个关键组合：清晨晴天、正午多云、午后下雨、晴天傍晚、晴朗夜晚、夜间降雪。额外核对阴雨傍晚、夜间浅色面板和白天深色面板。确定光照强度、天空范围、面板材质与动效存在感。

### B. 数据与静态背景

接入牧场坐标、时区、真实天气与太阳事件；完成缺失/过期/切换牧场状态；先验证静态场景和天气摘要。服务端凭据、区域数据可用性与供应商来源标识需在此阶段确认。

### C. 有限区域动画与详情

加入云、雨、雪、雾，完成天气详情、静态模式和自动降级。不要让天气效果改变业务加载与提交逻辑。

### D. 验收与上线

运行受影响的 Web 验证 gate；分别进行浏览器视觉、真实性与性能验证。预览、代码检查、真实天气服务联调和生产部署分别记录结果。

## 13. 验收清单

1. 同一时区不同经度的两个牧场有不同日出日落；设备时区改变不影响牧场天色。
2. 覆盖夏季/冬季、跨当地午夜、夏令时、无日出/无日落等边界。
3. 切换牧场时旧请求迟到不能污染新牧场；位置更新令旧缓存失效。
4. 日落后的 1 分钟不突然全黑；厚云夕照减弱；夜雨不显示太阳或满天星。
5. 降水概率不会触发当前雨景；雪不会凭空产生积雪。
6. 天气加载失败、部分字段缺失、太阳数据缺失、天气过期都能准确说明状态。
7. 浅色/深色内容主题与所有环境组合可读；320、390、768、1024 和 1440px 无横向溢出。
8. 正在填写表单时天气更新不丢输入、不移动焦点、不重置滚动。
9. 减少动态效果可实时生效；隐藏标签页不继续绘制；详情关闭后焦点返回摘要。
10. 网络日志与客户端包不包含服务端签名私钥；请求均有牧场授权校验。
11. 正式页面只显示真实工作区数据，演示选择器与示例天气不进入生产包。
12. 图标保持原始 App 导出资产，背景与天气效果通过实际桌面和移动浏览器视觉验收。
