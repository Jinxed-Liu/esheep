# 牧场首页设计核对（2026-09-27）

设计源：`pasture-approved.png`。在本地视觉验收页使用 1536 × 1024 和 390 × 844 视口检查。

| 对照点 | 实现结果 |
| --- | --- |
| 顶部品牌和导航 | 网页直接读取 App 导出的 `esheepplus-icon.png`；桌面保留五项横向导航，手机使用底部导航。 |
| 首屏背景与数字 | 晴空牧场背景、绿色标题和三项开放式指标与设计稿相符；正式页面的数字仍从 `workspace.metrics` 读取。 |
| 生产入口 | 两条摄影背景入口、左侧图标和文字层级已实现，点击分别进入羊只和圈舍。摄影素材与设计稿的场景略有差异。 |
| 今日操作 | 蓝色「新建记录」位于栏目标题右侧；称重、转群、投喂采用无套框的分隔行。 |
| 最近动态 | 三行时间、对象、事件和详情保留真实数据绑定；生产环境按事件实际同步状态显示。 |
| 手机布局 | 390px 页面没有横向溢出；修复了农场切换与账户头像挤压，生产入口文字有浅色遮罩。 |

视觉稿的具体羊只数量和记录是示例。浏览器核对使用本地独立验收页，没有连接云端或提交记录。已验证「新建记录」打开选择器、「羊只档案」进入现有羊只列表。
