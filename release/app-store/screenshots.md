# 3.1 screenshot acceptance

Produce separate Simplified Chinese and English sets for 6.9-inch iPhone and
13-inch iPad using the signed Production-configured build and real rendered
screens. Capture: home, flock, records, analysis, TMR, explicit cloud migration
and collaboration.

Reject a screenshot if it contains a debug banner/account, synthetic cloud
success, a subscription or purchase promise, clipped text, personal production
data without consent, or a state that cannot be reproduced by the review
account. Record device, locale, appearance, build number and source commit for
every final image.
