## 一、我们处理哪些信息

我们遵循目的明确、最小必要和公开透明原则。具体清单如下：

1. **账户和身份信息**：显示名、邮箱地址、Apple 登录返回的稳定用户标识及可能由用户允许提供的姓名、eSheep 账号 ID。用于注册、登录、邮箱验证、找回、安全通知和成员识别。密码由认证服务验证，App 不保存可读密码。
2. **设备与安全信息**：App 生成的设备 UUID、设备显示名、设备公钥、支持的数据协议版本、会话与安全状态。用于设备注册、会话安全、撤权、同步兼容和恢复。Face ID/Touch ID 模板由 Apple 在设备中处理，eSheep+ 不取得模板。
3. **牧场和协作信息**：牧场名称、地址文本、用户主动保存的坐标、时区、成员关系、角色、邀请标识，以及用户录入的羊只、圈舍、称重、繁殖、健康、防疫、药品、饲喂、配方、TMR、库存、成本、提醒、备注、附件和操作历史。用于记录、计算、导出、同步、恢复和按角色协作。
4. **照片、文件和扫码内容**：用户拍摄或主动选择的羊只、病症、耳标、票据、二维码及导入文件。只处理用户选择或拍摄的内容；不扫描整个相册。用于 AI 的图片会先缩放、重新编码并移除原文件中的 EXIF/位置元数据。
5. **位置与天气信息**：仅在用户主动设定牧场地点或使用相关天气功能时申请“使用 App 期间”的位置。用于保存牧场坐标、确定时区和请求对应天气；不是持续后台定位，不用于广告或人员轨迹画像。
6. **AI 助手内容（可选）**：用户问题、选定图片、主动录制的语音、当前会话历史，以及为回答问题而由本机工具返回的有限牧场数据。只有用户另行同意并主动发送时才提交 MiMo。原始 MiMo API Key 保存在本机钥匙串，并由设备直接向 MiMo 鉴权。
7. **服务和安全记录**：认证、同步、数据库、对象存储、邮件投递和账户删除任务可能产生时间、请求状态、错误码、IP 地址、设备/用户标识及必要的安全日志。用于防攻击、诊断、审计、恢复和履行法律义务。我们不在普通日志记录密码、完整令牌或 API Key。
8. **客服和权利请求信息**：联系邮箱、通信内容、身份核验所需的最少信息和处理记录。用于答复问题、处理个人信息权利和安全事件。

相机、麦克风、位置、照片、日历、提醒事项、通知、附近设备/本地网络等系统权限的具体用途见 App 内“权限说明”。拒绝非必要权限不会影响无关功能。

## 二、处理目的、方式和合法性基础

我们通过用户主动提供、设备本地生成、Apple 登录返回、受邀成员操作及服务运行时自动产生的方式处理信息，具体用于：

- 履行服务条款：创建和保护账户，提供离线记录、同步、协作、导入导出、恢复和客服；
- 取得同意后处理：位置、相机、麦克风、照片、日历/提醒、通知、AI 内容及依法需要同意的境外提供；
- 履行法定义务或应对安全事件：保存必要审计证据，防止欺诈、越权、攻击和数据损坏；
- 在紧急情况下保护自然人的生命健康和财产安全，且限于法律允许的必要范围；
- 法律、行政法规允许的其他情形。

处理目的、方式或信息种类发生实质变化时，我们会更新政策，并在法律要求时重新取得同意或单独同意。

## 三、设备本地处理

离线牧场记录、AI 会话、本机导入文件、钥匙串中的登录状态和 MiMo API Key、可选保留的已发送语音副本等可仅保存在当前设备。仅在设备内完成且未发送出设备的数据不属于 App Store 意义上的“收集”，但仍受本政策和设备安全措施保护。

默认不在本机长期保留已发送语音；用户可以在 AI 设置中主动开启。关闭后只影响后续语音，已保存副本可由用户删除或随对应会话/账户清理。

- **Supabase, Inc./Supabase Pte. Ltd. 及其基础设施子处理者**：认证、Postgres 数据库、对象存储、实时到达提示、备份与安全日志。生产项目区域为 `{{SUPABASE_REGION_COUNTRY}}`（计划值：新加坡，正式发布前按控制台实际区域确认）。

我们要求受托人仅按约定目的、期限和安全要求处理信息，并通过合同、权限、日志和定期复核进行监督。完整清单、链接、数据类别和状态见公开的“第三方与境外接收方清单”。

不要在 AI 输入中录入身份证号码、银行卡、自然人医疗记录、密码、API Key 或与问题无关的个人信息。

## 六、境外提供个人信息

云端账户、同步和 AI 功能可能将个人信息提供至中国大陆以外。核心云服务的境外接收方、国家/地区、目的、方式、种类和权利行使方式见《AI 与境外提供个人信息告知及单独同意》。登录页将“同意服务条款/隐私政策”和“同意必要的境外提供”分开勾选；AI 另行同意。

我们将按适用法律评估安全评估、个人信息保护认证、标准合同备案或其他条件。未完成接收方、地域、合同、数量阈值和保护措施核验前，不应把本草案视为已满足出境手续。境外司法或执法机构要求提供存储于中国境内的个人信息时，我们将依法取得中国主管机关批准。

用户可以撤回境外提供同意。撤回不影响撤回前处理的效力；由于账号和云同步依赖境外基础设施，撤回后我们将停止新的境外传输，并可能无法继续提供登录、云同步和协作功能，但会提供依法可行的数据导出、注销或本地数据处理路径。

## 七、保存期限和删除

我们按实现目的所需的最短期限保存信息：

| 数据 | 保存期限或确定方法 | 到期处理 |
|---|---|---|
| 本机牧场数据、附件、AI 会话 | 用户保留对应牧场/会话/账户期间；由用户删除或卸载清理（系统备份除外） | 删除本机记录和附件；钥匙串项目按注销/删除流程清理 |
| 活跃账号、成员与设备 | 账号存续及提供服务期间 | 注销后撤销会话、设备和成员关系并进入删除任务 |
| 云端牧场生产记录 | 牧场存续期间及保障账目、审计和协作所必需期间 | 用户删除牧场时删除可识别内容；为账目完整性确需保留的不可变操作历史进行去标识化 |
| 账户删除任务 | 无牧场所有权阻塞后目标 24 小时内完成主动库清理 | 删除或去标识化；保留任务状态作为合规证据 |
| 备份、安全和服务日志 | 以生产服务配置的最短期限为准，目标最长不超过 30 日，法律另有规定或安全调查除外 | 滚动覆盖、删除或不可逆匿名化；期间只进行存储和安全保护 |
| 客服和权利请求记录 | 为证明已响应及解决争议所需期间，通常不超过 3 年 | 删除或匿名化 |
| 影响评估和法定合规记录 | 法律要求的期限，影响评估报告和处理记录至少保存 3 年 | 期满后安全删除或归档 |

当处理目的已实现、无法实现、不再必要、保存期限届满、用户撤回同意、注销账号或我们违反约定/法律处理时，我们依法删除或匿名化。法律规定的保存期未届满或技术上暂难删除的，将停止除存储和必要安全保护之外的处理。

我们采用传输加密、iOS Keychain、设备密钥、Supabase 行级安全策略、受控 RPC、私有对象存储桶、按角色授权、会话撤销、图片重编码去元数据、日志脱敏、备份与恢复检查等措施。任何互联网服务都无法保证绝对安全；如发生或可能发生泄露、篡改、丢失，我们会立即补救，并在法律要求时通知保护部门和受影响个人，说明种类、原因、可能危害、已采取措施及联系方式。

## 九、个人的权利

在适用法律范围内，用户可以：

- 查阅、复制其个人信息并要求解释处理规则；
- 请求更正、补充、删除或限制处理；
- 在符合法定条件时请求转移；
- 撤回基于同意的处理；
- 退出共享牧场或要求调整成员权限；
- 在 App 内注销账号；
- 对我们的处理进行投诉。

可通过 App 内设置或 `{{PRIVACY_EMAIL}}` 提交请求。我们会先进行最小必要的身份和权限核验，通常以 15 个工作日作为内部处理目标；法律另有规定的从其规定。拒绝请求时会说明理由和进一步投诉途径。注销前，牧场主需先导出并转移或删除其拥有的牧场，避免损害其他成员和账目完整性。

## 十、未成年人

本服务面向具有完全民事行为能力的牧场经营者和工作人员，不面向不满十四周岁的未成年人。若发现未经监护人同意处理了不满十四周岁未成年人的个人信息，我们将暂停相关处理、联系监护人并依法删除。未来若专门面向未成年人提供服务，将先制定专门规则并取得监护人同意。
