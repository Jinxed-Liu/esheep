# 综合搜索与繁殖历史导航验收（2026-10-28）

## 实现

独立搜索统一检索羊只、羊舍和现有事件；按类别显示数量和结果，并复用详情及权限、修正入口。搜索筛选条以屏幕为边界，调整顶部位置，键盘展开时末项可完整滚动至搜索栏上方，移除搜索范围说明卡片。

从首页“在场羊只”进入档案后，原来的繁殖历史 value 路由会与现有 view destination 混用，重新叠出羊只详情。该入口改为直接的 view destination，保留繁殖历史的稳定输入和动态数据查询。回归用例从真实工作区的首页及搜索入口启动，各连续完成三轮“羊只 → 繁殖历史 → 产羔详情 → 历史 → 羊只”，再验证一次返回原列表及关键词保留。没有修改牧场业务事实或数据管道。
