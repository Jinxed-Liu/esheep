# eSheep+ 3.1 隐私数据清单

本清单是 App 内法律文本、公开隐私政策、`PrivacyInfo.xcprivacy` 与
App Store Connect 隐私问卷的唯一维护来源。任何一处变更都必须同步
更新其余三处并重新生成 Xcode 聚合隐私报告。

## 生产收集范围

| 数据 | 来源与用途 | 存储/处理方 | 关联用户 | 跟踪 |
| --- | --- | --- | --- | --- |
| 姓名/显示名 | 账号显示与牧场协作 | Supabase Auth/Postgres | 是 | 否 |
| 邮箱地址 | 注册、验证、重置密码和安全通知 | Supabase Auth/SMTP | 是 | 否 |
| 精确位置 | 用户明确保存的牧场位置、天气和时区 | Supabase 牧场数据 | 是 | 否 |
| 照片 | 羊只及生产记录附件 | Supabase Storage | 是 | 否 |
| 其他用户内容 | 牧场、羊只、健康、繁殖、饲喂、TMR、备注和历史 | Supabase Postgres/Storage | 是 | 否 |
| 用户 ID | 登录、成员关系、权限、审计与恢复 | Supabase Auth/Postgres | 是 | 否 |
| 设备 ID | 同步设备注册、撤权和协议兼容 | Supabase Postgres | 是 | 否 |

不收集广告标识符，不进行跨 App/网站跟踪，不出售个人数据。动物健康和
繁殖数据属于用户的生产业务内容，不声明为人的 HealthKit/医疗健康数据。

## Required Reason API

- `UserDefaults`：`CA92.1` 用于 App 自身设置；`1C8F.1` 用于 App 与 Widget
  之间的 App Group 状态。
- 文件时间戳：`C617.1` 用于 App 容器内恢复进度文件的新旧校验。

## 发布前核对

- 由正式版 Xcode 对 Release Archive 生成聚合隐私报告。
- 核对 Supabase Swift 及其他打包依赖的隐私清单和签名。
- 核对 Production Auth 日志、SMTP 提供商和 Supabase 平台日志是否引入
  IP 地址、诊断或其他新增数据类型；若引入，先更新本清单再提交。
- App Store Connect 中所有已收集数据均选择“App 功能”，关联用户，
  不用于跟踪。
