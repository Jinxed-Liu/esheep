# 3.1.1（20）内测使用清单

本次按用户要求不运行测试，由用户实际使用确认。

1. TestFlight 全新安装后登录原 Apple 账号，进入星露谷牧场。观察首次下载进度是否继续推进、退出重开能否继续。检查点本体约 9.84 MB，照片及后续增量另计。
2. 看首页羊只、圈舍，检查称重、投喂、繁殖产羔、生产批次、转圈和死淘历史；特别留意之前的死亡记录及最近上传的操作。
3. 正常录入一条真实记录，在 eSheep+ 云页面确认已安全保存，再退出重开确认记录仍在。不要为了测试填写虚假生产数据。
4. 留意连续输入、耳号选择、首页与云页面滚动是否卡顿；记录出问题的页面与操作。
5. 下载完成后断网查看历史，恢复网络后确认新操作继续保存。
6. 查看云页面业务及同步数据、接收文件和照片分别占用多少。

已知限制：此前 Build 19 曾捕获短暂停顿，本次没有新增性能测试，也不宣称完全消除；每日自动更新检查点的 CI 后续接通，当前检查点之后的数据通过增量接收。
