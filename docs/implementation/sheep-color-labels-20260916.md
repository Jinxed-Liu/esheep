# 羊只十色标签：开发版界面交接

## 已确认的展示规则

有头像显示照片；没有头像时公羊显示黄色耳标、母羊显示绿色耳标；未知性别显示中性符号与原性别文字。默认性别标记不计入自定义标签，不在耳号旁重复显示。

自定义标签十色、牧场共享、多标签及主标签。黄色仅公羊，绿色仅母羊；未知性别只可使用其余八色。停用保留关联、禁止新增，主标签回退有效排序最前项。
