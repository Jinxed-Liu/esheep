### 必验动作

- [ ] 事件分级、总协调人和单一事实源建立
- [ ] 会话/密钥/存储/RLS 等止损动作完成且可回滚
- [ ] 保全数据库日志、访问日志、构建与配置版本，未污染原始证据
- [ ] 识别数据种类、人数、时间范围、敏感程度与可能危害
- [ ] 联系相关受托人并取得事件编号/响应承诺
- [ ] 判断是否需要通知保护部门与个人，并准备通俗、准确、不隐瞒的通知
- [ ] 验证恢复、持续监控与同类风险排查
- [ ] 形成根因分析、整改责任人和完成时限
